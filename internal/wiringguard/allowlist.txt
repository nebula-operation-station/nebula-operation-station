# Allowlist for internal/wiringguard.
#
# One package per line: <package path> | <reason> | <ticket ID>
# Every field is required. A listed package is not reachable from cmd/; the
# reason says why and starts with one of three categories:
#
#   planned: <what>                       the ticket wires the package; remove
#                                         the line when it gets an importer
#   test helper - never wired: <what>     imported by tests only, by design;
#                                         never triage it as "wire or remove"
#   developer tool: <what>                a command run by hand or by make
#                                         check, never by a product command
#
# The ticket ID must be defined by a table row or heading of a Markdown file
# under docs/, or be registered in internal/wiringguard/tickets.txt with an
# existing docs/ tracking document. TestRealTreeTicketsExist checks this.
