Deploy Profiles

A deploy profile is a secret-free preset for provisioning a guest: size (S/M/L/XL or a bounded custom size), image, network and DNS, the bootstrap modules to run, the runbooks it references and the vault entries it needs (references only — no secret values ever). Every save is a new, unchangeable version; provisioning always uses the exact version it was planned with.
