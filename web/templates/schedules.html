Scheduled checks

A schedule lets Nebula run read-only checks on its own, for example a daily update check. You approve it once with your security key. The executor accepts only actions it rates LOW: the built-in script must be trusted as LOW on the executor host (nebula-server -export-actions and nebula artifact trust, see the guide) and the host recorded with a criticality. It runs each action on each host at most once per interval, until the schedule expires or you revoke it.
