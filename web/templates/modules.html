Modules

A module bundles actions written by someone else. Import the archive made by nebula module pack. The executor checks the author's SSH signature itself: a module signed by a signer you trusted on the executor host (nebula signer add) is verified and its actions run at their declared risk; any other module is unverified and its actions need your security key every time (at least HIGH). Modules never run code on the Nebula machine. Runbooks are your own scripts.
